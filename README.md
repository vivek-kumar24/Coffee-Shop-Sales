# Coffee-Shop-Sales Dashboard (Excel Project)
##Overview
This project builds an interactive Excel dashboard for a multi-location coffee shop chain. The dashboard tracks sales, footfall, and product performance to support day-to-day decision-making.
⚙️Tools & Technologies:
-Microsoft Excel (Pivot Tables, Slicers, Charts, Power Query, Conditional Formatting)

🔍Key Analysis:
-Total sales ($540K+) and total orders (115K+) analysis.
-Sales performance by day of week, hour of day, and product category (coffee, tea, bakery).
-Customer behavior metrics like average bill per person and product demand.
-Dynamic filtering by time period (month/day) for real-time insights.

📊Outcomes:
-Helped identify top-selling products and peak hours for demand planning.
-Improved visibility of category contributions to overall sales.
-Delivered a flexible dashboard for both store-level and regional performance monitoring.
